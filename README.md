# Reflectie op mijn portfolio

Tijdens het maken van mijn portfolio heb ik gewerkt met HTML, CSS en JavaScript. Over het algemeen ben ik best tevreden met het resultaat en hoe ik het project heb aangepakt.

**CSS en responsive design**

CSS en het responsive maken van de website vond ik soms lastig. Vooral flexboxes waren in het begin moeilijk, maar uiteindelijk begon ik het steeds beter te begrijpen. Hier wil ik nog wat meer mee oefenen.

**JavaScript**

De JavaScript die ik heb gebruikt begrijp ik redelijk goed. Toch merk ik dat ik hier veel meer moeite mee heb dan met HTML en CSS. Ik wil daarom meer oefenen met JavaScript, zodat ik het steeds beter zelfstandig kan gebruiken.

**Problemen oplossen**

Kleine problemen in HTML en CSS oplossen vond ik vrij makkelijk. Meestal kon ik snel vinden wat er fout ging en dit oplossen.

**Het ontwerp**

Ik gebruikte de geleverde wireframe als voorbeeld. Deze heb ik grotendeels aangehouden waar dat moest, maar ik heb er ook mijn eigen ideeën aan toegevoegd om de website mijnn eigen leuk te geven.

**Overzicht houden**

Ik vind dat ik mijn project netjes heb opgebouwd. Ik heb de bestanden in aparte mappen gezet, waardoor alles overzichtelijk bleef.

**Conclusie**

Ik ben tevreden met hoe mijn portfolio is geworden. Mijn grootste verbeterpunt is JavaScript, omdat ik daar nog wat moeite mee heb. Bij een volgend project wil ik hier meer mee oefenen en ook blijven werken aan mijn CSS-vaardigheden.
